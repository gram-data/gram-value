# Specification

The normative text of what each gram value means: how a value is interpreted, what its canonical text form is,
and what an interpretation of a tagged string must check. It does not define syntax: the
[tree-sitter-gram](https://github.com/gram-data/tree-sitter-gram) grammar and test corpus are the authority for
what text is a gram value, and this specification refers to them.

Empty until RFC-001 is accepted.
